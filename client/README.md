# DevPulse Frontend Client

Production frontend for the DevPulse platform built with:
- **React 18** with functional components & hooks
- **Vite 7** for lightning-fast HMR and optimized production bundling
- **Redux Toolkit & Redux Persist** for client state management
- **Tailwind CSS & Flowbite React** for glassmorphism styling and dark mode
- **DOMPurify** for XSS security sanitization

## Available Scripts

- `npm run dev`: Launch Vite local development server
- `npm run build`: Compile and minify assets into `dist/`
- `npm run preview`: Preview production build locally
